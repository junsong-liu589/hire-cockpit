# Hire Cockpit PWA 使用手册

## 打开和安装

通过发布者提供的 HTTPS 固定网址打开 Hire Cockpit。首次联网访问后，可以继续以网页使用；支持 PWA 安装的浏览器也会提供“安装应用”或“添加到主屏幕”，安装后可以像普通应用一样从桌面/主屏幕启动。首次打开需要联网加载程序；加载完成后，已访问过的应用外壳可以离线打开。招聘官网等外部网页仍需联网。

## 数据保存在哪里

企业、岗位、投递、日程、简历附件、个人资料和设置保存在**当前设备、当前浏览器配置文件**的 IndexedDB。本应用不把这些业务数据上传到 GitHub Pages 或服务器，也不需要登录、Docker 或 AI 密钥。无 AI 密钥时，常规记录、匹配和分析均可使用。

不同电脑、不同浏览器、不同浏览器配置文件/隐私窗口各有一份独立数据，不会自动同步给舍友。舍友打开相同网址后使用自己的本地工作区。请不要把含个人信息的备份发给其他人。

关闭标签页、退出浏览器或重新启动设备后，通常仍可看到已保存内容。**不要清理浏览器的网站数据/缓存，不要重置或卸载浏览器后才备份。**浏览器或设备故障、磁盘空间不足、隐私清理软件和用户主动清理站点数据都可能造成数据丢失。应用会请求浏览器保留本地数据；这个请求由浏览器决定，不能替代备份。建议每次重要更新后导出备份，并把文件另存到 OneDrive/网盘/U 盘等另一个位置。

## 导出备份（建议定期做）

1. 打开左侧“设置”。
2. 在“备份与恢复”中选择“导出工作区备份”。
3. 浏览器会下载 `hire-cockpit-backup-日期.json`。确认文件实际出现在下载目录。
4. 将它复制到另一个安全位置；只放在电脑下载目录不算异地备份。

备份包含当前工作区的业务记录和简历附件，可能含手机号、邮箱、求职资料等敏感内容。不要提交到代码仓库或公开分享；需要通过网盘转移时，使用可信的私人空间。

## 恢复备份

1. 先从“设置”导出当前浏览器数据，作为恢复前的回退副本。
2. 选择“恢复备份”，选取此前导出的 `.json` 文件。
3. 检查预览中的记录数、附件数和替换提示。
4. 点击“确认替换并恢复”，并在二次确认框中确认。
5. 恢复会用备份整体替换当前浏览器中的业务数据。完成后检查企业、岗位、投递和附件。

把备份导入舍友的浏览器，会把数据复制到舍友的本地工作区；之后两边各自变化，不会同步。注意：恢复当前实现只接受本 PWA 导出的版本化 JSON 格式。

## 简历附件

添加简历版本时，可选择 PDF、PNG 或 JPG 附件，单个文件最大 20 MiB。附件与记录一同存在浏览器数据库内；通过简历页面“下载附件”可取回。导出的 JSON 备份也包含附件数据，所以附件多或较大时备份文件会相应变大。若浏览器报告空间不足，请删除不需要的附件或留出设备空间后重试。

## 进阶求职 Agent 与投递流程

### 从资料中生成待确认记录

在“资料 Agent”选择 TXT、Markdown、CSV、DOCX 或 PDF 文件，也可以粘贴文字。解析在当前浏览器中完成，单文件最大 25 MiB；不会上传文档。系统会按明确的字段标签和规则识别企业、岗位、投递、待办和个人资料，并给出来源片段、识别把握和可能重复项。它不是云端大模型，也不会理解所有自由文本。

检查每项建议，调整字段、关联已有企业/岗位，取消不想导入的勾选；只有点击“确认并写入本机”后才会写入。识别不准时直接修改建议，或者不确认导入。当前支持格式的可读文字提取；扫描版 PDF 图片中的文字不会自动 OCR。

### 本地岗位匹配

在“岗位匹配 Agent”设置目标方向、城市、必需/加分/排除关键词、薪资和学历偏好。偏好保存在当前浏览器。可对已保存岗位重新查看匹配解释，也可粘贴职位描述进行本地解析。结果会列出得分依据、条件缺失和不确定点；它是规则辅助，不代表招聘方结论。

新岗位需要你核对解析出的企业和职位字段，再点击“确认并加入本机岗位库”。排除项默认阻止保存；如果仍要记录，先勾选确认你已核对原因。系统不会访问招聘平台，不会替你搜索职位或投递。

### 配置和运行投递工作流

在“投递工作流”从本机未投递岗位启动模板。模板可改名称、步骤标题和跟进间隔；人工批准、人工登记投递和跟进等核心步骤不能关闭。工作流开始时会保存当时的岗位匹配结果。

可选地关联简历或填写材料准备说明；到人工批准时明确确认后才会继续。之后你需要亲自去招聘网站投递，再填写渠道并确认已提交，系统才会在本机登记投递；最后会创建真实的本机跟进待办。暂停、恢复和撤销会写入步骤历史。撤销会停止自动推进，但保留已经创建的投递和待办。

流程不会在页面关闭后后台运行，也不会登录招聘平台、发送申请或联系招聘者。重开应用后可继续查看流程和历史。删除关联企业或岗位时，关联的工作流记录也会一并删除。

## 删除记录

企业、岗位、投递、待办、笔试、面试、面经、Offer、简历版本、附件、个人资料、匹配规则和站内提醒都可在对应模块中删除。删除前会弹出确认框；企业、岗位和投递会说明受影响的关联数据。删除操作不可撤销，重要数据建议先导出备份。

- 删除企业会同时删除该企业的岗位及其关联投递、状态历史、待办、笔试、面试、Offer 和面经。简历和个人资料仍保留。
- 删除岗位会同时删除该岗位的投递及其状态历史、笔试、面试、Offer、关联待办和面经；所属企业保留。
- 删除单条投递会同时删除其状态历史、笔试、面试和 Offer；企业与岗位保留。
- 删除简历版本会解除申请中引用的简历绑定。如果附件未被其他简历共用，也会一并删除。单独删除附件会解除所有简历上的该附件绑定。
- “设置”中的“清空此浏览器全部数据”会清除当前浏览器内所有记录和设置，并要求再次确认。它只影响当前浏览器配置文件。

## 安全与隐私提示

- 浏览器本地数据没有服务器端账号、云端同步或服务器加密。设备账户和浏览器配置文件应设密码；共享电脑上不要保存敏感个人资料。
- 公开发布的网址只托管应用程序文件；每人的业务数据留在自己的浏览器里。浏览器扩展、恶意软件或能运行在此网站来源下的恶意代码可能读取本地数据。
- 招聘链接草稿需要人工打开网页并复制职位信息。出于浏览器跨域限制，静态 PWA 不会声称能自动抓取所有招聘网站。草稿在点击“我已核对，确认加入岗位库”前不会新增岗位。
- 提醒在打开应用时更新，不会在应用关闭时保证后台通知送达。

## 常见问题

**换了电脑后看不到数据？** 这是预期行为。原设备“设置 → 导出工作区备份”，在新设备打开同一网址并“恢复备份”。

**清浏览器数据后数据消失？** 浏览器清理网站存储可能永久删除本地记录。若有备份，可按恢复步骤导入；没有备份时无法从服务器找回。

**是否要配置 Docker 或 API 密钥？** 不需要。发布后的 PWA 是静态应用，核心功能直接在浏览器本地运行。

**链接点开仍显示旧版？** 先联网重新打开，等待页面更新；如果仍旧，可关闭并重新打开已安装应用。不要为了刷新而清除网站存储，因为业务数据也在其中。
